# Artur Secret Scrum Announcement — V2 🐶

A static Portuguese hangman-style Scrum announcement.

## V2 changes
- The maximum number of wrong attempts is intentionally hidden from the UI.
- The game silently keeps the 12-attempt limit, while Artur and the status messages react to mistakes.
- The reveal is staged: **ARTUR** appears first, then **IRMÃO!** with a larger animation/glow and confetti.
- The final photos appear only after the word animation completes.
- Mobile-friendly and deployable as a static GitHub Pages site.

## Run locally
Open `index.html` in a browser, or serve the directory with any static HTTP server.

## Deploy
Push the folder contents to a GitHub repository and enable GitHub Pages.
